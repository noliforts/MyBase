# MyBase — Собственная СУБД

Учебный проект. Реляционная база данных с поддержкой SQL-подобного языка запросов.

## Состав

| Модуль | Тип | Назначение |
|---|---|---|
| `db_core` | Статическая библиотека | Парсер, движок таблиц, хранилище |
| `db_server` | Исполняемый файл | Сервер, слушает порт |
| `db_client_lib` | Библиотека | API для клиентов |
| `db_client` | Исполняемый файл | Консольный интерфейс |
